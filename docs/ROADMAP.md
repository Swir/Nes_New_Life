# NES New Life Roadmap

## Project #002 — Tiny Toon Visual Remaster

### Phase 1 — HD-pack foundation (current)
- validate user-supplied ROM fingerprint and mapper
- local CHR reference exporter
- local workspace generator
- Mesen HD Pack validator
- simple remaster studio GUI
- safe repository rules: no ROM/capture distribution

### Phase 2 — complete capture
- configure Mesen HD Pack Builder
- record every world, menu, animation, boss and effect
- measure capture coverage and duplicate/conflicting tiles
- split capture sheets into logical art groups

### Phase 3 — modern art pass
- player animation replacements
- enemies and bosses
- foreground tilesets and scenery
- backgrounds, UI and effects
- visual consistency at 4x scale

### Phase 4 — polish
- optional audio replacement
- controller profile documentation
- visual regression screenshots/checklist
- packaged HD Pack installer that contains no ROM

The ROM remains the gameplay source throughout all phases.
