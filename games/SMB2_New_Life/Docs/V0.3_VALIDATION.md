# SMB2 New Life v0.3 validation checklist

This milestone received a static source/configuration review. A real Unity 6.3 LTS Editor run is still required before publishing a tested binary release.

## Compile / generation
- [ ] Open `games/SMB2_New_Life/UnityProject` in Unity 6.3 LTS
- [ ] Confirm zero C# compile errors
- [ ] Run `NES New Life > SMB2 > Create PLAYABLE Level`
- [ ] Confirm `SMB2_Playable.unity` is generated and opens

## World flow
- [ ] Select each character with 1/2/3/4
- [ ] Enter the surface door with Up/W
- [ ] Confirm camera changes to underground room bounds
- [ ] Collect the underground key
- [ ] Confirm HUD key counter increments
- [ ] Try locked door without a key and confirm it refuses entry
- [ ] Use a key on the locked door and confirm the key is consumed
- [ ] Confirm player appears behind the mandatory surface barrier
- [ ] Confirm camera returns to surface bounds

## Pullable items
- [ ] Crouch next to a green plant
- [ ] Press Shift and confirm the buried item is pulled into the carry position
- [ ] Throw it at an enemy and confirm damage
- [ ] Confirm pulled plant cannot be pulled twice

## Existing gameplay regression
- [ ] HP / invulnerability / knockback
- [ ] death / lives / respawn
- [ ] checkpoint
- [ ] pause / resume
- [ ] miniboss fight
- [ ] goal locked until miniboss defeat
- [ ] win / replay

## Windows build
- [ ] Run `NES New Life > SMB2 > Build Windows x64`
- [ ] Launch generated EXE on Windows
- [ ] Complete one full run without a softlock
